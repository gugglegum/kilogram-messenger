## Binding amendments

1. Freshness is measured conservatively from the monotonic START of the status request, not merely when a possibly delayed response arrives. Preserve run/generation/request identity. A response already older than2s cannot refresh the connected badge; delayed/old/cancelled results cannot make a newer run green. Expiry/error/owned exit/stop also clear it. One in-flight request remains the bound. Add a deterministic delayed-result test; no long sleep or full transport campaign is needed for this UI projection case.

2. Preserve the prior Profile2 file acceptance rules as well as default values. The existing #[serde(default)] numeric quotas accept missing fields and reject explicit null. A naive Option quota DTO plus unwrap_or(default) would silently accept null: do not introduce that relaxation. Use a narrow deserializer/conversion retaining missing-vs-null behavior (or another equally small representation). Desktop-created/reused profiles require explicit exact quotas. Focused shared-schema compatibility checks cover existing emitted documents, omitted defaults, explicit null, wrong types/unknown/duplicate fields, and retained authoritative route/quota checks. Do not broaden the profile modes or refactor unrelated profile variants.

Correct the offline acceptance row: saved Accepted alone is insufficient, but an actually missing slot plus the valid exact retained final is precisely what the existing idempotent import can repair. Start may proceed AFTER the real recheck installs/confirms both slots. Missing/invalid finals, conflicting installed consent, incomplete recheck or foreign lock block Start. Test both successful missing-slot recovery and conflict refusal; do not write a test expecting a valid recheck to fail. Do not recreate stores or silently renew consent.

4. A pinned client is not switched by later descriptor-file replacement. Stop uses only a client previously bound to this live owned run. Unexpected replacement is an error/conflict, never a reason to reload and send Shutdown to the replacement. Keep stale-descriptor startup read-only until the owned runtime replaces its own artifact; no deletion of arbitrary files. Apply cancellation/close/start-failure cleanup through the held Child handle and observe exit; lifecycle state is not relinquished while a child may still own the store.
