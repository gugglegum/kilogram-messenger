# T1.2d.1. Уборка helper до запуска runtime

База `27b8d0315f37652b654ba2b11cf1216588528fd0`. Обычная потеря ответа от завершившегося profile helper по-прежнему допускает принятие точного Profile2. `Cancelled` прекращает подготовку, сохраняя файл для явного повтора. Типизированный `CleanupUnconfirmed` от profile или consent helper останавливает подготовку даже при наличии точного файла. Ошибка остаётся доступна через цепочку причин. [Подготовка профиля](../../crates/kilogram-first-dialog/src/connection.rs#L255)

При возврате из `Work` флаг передаётся вместе с владеющим lock объектом Setup. Новый `Work` с этим Setup отклоняется. GUI удерживает возвращённый Setup и показывает отказ вместо повторного запуска. Chat учитывает флаг даже до spawn, блокирует повторный connect и возвращает ошибку закрытия; терминальный координатор использует действующий абсолютный дедлайн и ненулевой exit. Флаг существует в памяти владельца. Схема Setup и путь остановки уже запущенного runtime сохранены. [Передача и проверка флага](../../crates/kilogram-first-dialog/src/chat.rs#L339) · [Обработка GUI](../../apps/kilogram-windows/src/fresh_onboarding/mod.rs#L649) · [Код завершения терминала](../../apps/kilogram-cli/src/terminal_chat/coordinator.rs#L725)

## Проверки

- `build02` подтвердил offline locked сборку CLI, bootstrap и Windows GUI. Использованы Idle и одно задание. Предыдущие принятые образы T1.2c и новые байты сборки сохранены в отдельных архивах. [Квитанция](../../.tmp/terminal-t1-2d-1/build02.receipt.json)
- `focused02` на свежей локальной паре использовал реальные helper и обычный запуск одного runtime с последующей штатной остановкой. Узкая тестовая подстановка воспроизвела потерянный ACK, чистую отмену и неподтверждённое завершение. При точном файле обычная ошибка позволила подготовить профиль. Отмена сохранила точный файл без digest и допускала обычный повтор. `CleanupUnconfirmed` имел приоритет над отменой. Точный файл сохранился, runtime не запустился, новый `Work` из возвращённого Setup был отклонён. Проверка consent helper до spawn передала ошибку Chat и подтвердила отказ ограниченного disconnect и повторного start. [Тест](../../crates/kilogram-first-dialog/src/connection_tests.rs#L50) · [Вывод](../../.tmp/terminal-t1-2d-1/focused02.stdout.log)
- `close02` через стабильный CLI harness подтвердил ненулевой exit при неподтверждённом закрытии по абсолютному дедлайну, включая занятый writer. Все три зачётные квитанции содержат exit 0 обёртки и тестового процесса, EOF и пустой Windows Job после штатного завершения. [Вывод](../../.tmp/terminal-t1-2d-1/close02.stdout.log)

В `focused01` исправлено сравнение типов строк в тесте. У `build01` и `close01` child вернул 0, после чего обёртка завершила остаточный `vctip` в своём Job. Их логи и квитанции сохранены. GUI проверен сборкой и общим путём возврата Setup из `Work`. Ручной GUI-прогон и сценарий D.2 остаются за пределами этой проверки. [Контракт D.2](terminal-t1-2d-contract.md)
