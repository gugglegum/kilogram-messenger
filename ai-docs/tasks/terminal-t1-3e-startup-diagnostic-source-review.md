The old C# Exchange required done(seq-1) before publishing any successor. Next forwarded only while pending==null. Thus the old bridge could neither deliver status nor deliver protocol-supported quit preemption while connect was outstanding. It supports a cleanup confounder; it does not establish the internal cause of B's delay or every reason for forced cleanup.

## Minimal correlation/preemption change

MailboxTerminal now keeps at most192 known request entries keyed by its existing IDs. Each exact request payload/sequence is retained; transport uncertainty retries the same immutable bytes. Maximum4 adapter submission attempts per entry, with existing client retries sharing the caller's end. Before quit follows a connect with uncertain delivery, the adapter reconciles that SAME predecessor, so it never skips a missing command sequence. A timed-out connect is not replaced with a new connect ID. Status first reconciles the outstanding connect; it is not forwarded concurrently.

The C# bridge permits exactly one additional pending command: **quit following one connect**, with no skipped predecessor and no other unresolved earlier command. Setup forwarding stays serial; only Chat's FeedInput can forward this exception. Pending entries retain their own sequence/op, so both completion files correspond to the correct IDs even if quit's reply is seen first. A successful connect is not a quit acknowledgement. Product quit/cancel logic is unchanged.

Known late replies are stored rather than consumed as another operation. Unknown IDs, repeated results and unresolved EOF fail closed; incoming events retain their order and existing32-event bound. A clean quit additionally requires all known requests resolved, clean mailbox terminal/streams and owner exit0. Command lifecycle artifacts preserve full public connect/quit results, while other command bodies are omitted and requests have only payload hashes. Existing16KiB public frame/512-cursor/192-command caps remain. No plaintext message, recovery word, key or private helper output is newly exported.
