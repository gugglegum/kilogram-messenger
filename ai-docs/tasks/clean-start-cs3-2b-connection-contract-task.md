Choose a narrow reusable typed validation strategy rather than ad hoc permissive JSON. Paths are locally chosen outside device/Root state; no-clobber creation and exact validated reuse after interruption. No new Root access in runtime.
- kilogram_runtime_ipc::call currently loads/verifies its descriptor internally. A UI check of a path followed by call(path) may check different bytes if the file changes. Preserve signature/token/address checks, bounded framing and sanitized errors; descriptor/token/claim/path never enters peer exchange.
