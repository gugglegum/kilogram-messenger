# M0.9.87 — полевой тест двух разделённых volunteer providers

Статус: комплект реализован; внешний запуск ещё не принят.

## Сколько устройств нужно

Минимум: три физических устройства.

- устройство A запускает Alice из папки `1`;
- устройство B запускает Provider 1 из папки `2` и может также запускать Bob
  из папки `4`;
- устройство C запускает Provider 2 из папки `3`.

Идеальный вариант — четыре устройства, по одному на каждую роль. Provider 1 и
Provider 2 обязательно должны быть на разных физических компьютерах, в разных
сетях доступа и у разных операторов. Совместное размещение Bob и одного
provider допустимо, потому что проверяется независимость именно двух хранилищ.

## Что вводят provider-скрипты

Каждый provider один раз спросит две короткие метки:

- оператора, например `home-isp-a` или `mobile-operator-b`;
- сети, например `alice-ethernet` или `phone-hotspot`.

Одинаковому оператору или сети нужно давать одинаковую нормализованную метку.
В evidence попадают только run-scoped SHA-256 digests; сами строки и raw
`MachineGuid` не сохраняются. Эти различия подтверждают контролируемую
постановку теста, но не являются криптографическим доказательством реальной
принадлежности к разным операторам.

## Порядок запуска

После генерации свежего комплекта и его полной синхронизации:

1. На Alice из папки `1` запустить `01_PREPARE_ALICE.ps1` и оставить окно.
2. На первом provider-хосте из папки `2` запустить
   `01_START_PROVIDER1.ps1` и оставить окно.
3. На втором provider-хосте из папки `3` запустить
   `01_START_PROVIDER2.ps1` и оставить окно.
4. На Bob из папки `4` запустить `01_PREPARE_BOB.ps1` и дождаться успешной
   подготовки Alice и Bob.
5. На Alice из папки `1` запустить `02_SEND_ALICE.ps1`.
6. На Bob из папки `4` запустить `02_RECEIVE_BOB.ps1`.
7. На Alice из папки `1` запустить `03_VERIFY.ps1`. Он создаст общий stop
   marker, дождётся закрытых provider logs и выполнит fail-closed проверку.

Каждый файл запускается из своей папки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\ИМЯ_СКРИПТА.ps1
```

VPN на всех участниках и Wi-Fi на телефоне с мобильной раздачей должны быть
заранее отключены, если цель конкретного прогона — разные реальные сети.

## Что считается успехом

Финальный скрипт должен вывести:

```text
M0.9.87 INDEPENDENT-PROVIDER SERVICE-FREE FIELD TEST COMPLETED SUCCESSFULLY.
```

При этом verifier требует два разных machine/operator/network digest, exact
signed receipts `2/2`, остановленную Alice до чтения Bob, две доставки из
volunteer Iroh stores, delete-after-commit и отсутствие повторной доставки
после restart.
