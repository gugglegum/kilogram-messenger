# M0.9.87 two-host reduced — тест на ПК и ноутбуке

Это упрощённый прогон полного service-free lifecycle на двух физических
Windows-устройствах:

- ПК: Alice + Provider 1;
- ноутбук: Provider 2 + Bob.

Он проверяет отправку, две volunteer-копии, выключение Alice до получения,
чтение Bob, удаление после commit и отсутствие повторной доставки после
restart. Результат **не является independent-provider field acceptance**:
provider совмещён с конечным клиентом на каждом из двух хостов, а разные
операторы и сети не требуются.

## Перед началом

1. Дождитесь полной синхронизации всей папки через Яндекс Диск.
2. Не переносите папки `1`, `2`, `3`, `4` отдельно: общий каталог нужен всем
   ролям для синхронизации marker/evidence-файлов.
3. Запускайте каждый файл в новом окне PowerShell из указанной подпапки.
4. Если хотите проверить связь через мобильную сеть, заранее отключите VPN на
   обоих устройствах и Wi-Fi на раздающем телефоне. Для самого reduced-теста
   одинаковая сеть также допустима.
5. Provider-скрипты спрашивают метки оператора и сети. Вводите правду. Если
   provider используют один Интернет-канал, укажите им одинаковые метки.

Команда запуска во всех окнах одинакова:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\ИМЯ_СКРИПТА.ps1
```

## Порядок запуска

1. На ПК, папка `1`: `01_PREPARE_ALICE.ps1` — окно оставить работать.
2. На ПК, папка `2`: `01_START_PROVIDER1.ps1` — второе окно оставить работать.
3. На ноутбуке, папка `3`: `01_START_PROVIDER2.ps1` — окно оставить работать.
4. На ноутбуке, папка `4`: `01_PREPARE_BOB.ps1` — второе окно оставить до
   сообщения об успешной подготовке Alice и Bob.
5. На ПК, папка `1`: `02_SEND_ALICE.ps1`.
6. На ноутбуке, папка `4`: `02_RECEIVE_BOB.ps1`.
7. На ПК, папка `1`: `03_VERIFY.ps1`.

Не закрывайте provider-окна вручную: `03_VERIFY.ps1` создаст stop marker, оба
provider корректно закроют runtime и опубликуют финальные логи.

## Успешный результат

В конце шага 7 должны появиться обе строки:

```text
M0.9.87 TWO-HOST REDUCED SERVICE-FREE TEST COMPLETED SUCCESSFULLY.
This result is not independent-provider field acceptance.
```

Если скрипт завершился ошибкой, не возобновляйте старый run и не удаляйте
отдельные marker-файлы. Сохраните текст ошибки: для следующей попытки будет
создан свежий комплект.
